# Прототип раздела «Услуги» — Office8

Кликабельный макет страницы «Услуги» и 13 страниц отдельных услуг в стиле office8.kz.

## Как открыть

Двойной клик по `index.html` — откроется страница «Услуги», дальше всё по ссылкам.
Нужен интернет: шрифт Montserrat, Tailwind, иконки, фото и фавикон грузятся из сети.

## Что внутри

| Файл | Что это |
| --- | --- |
| `index.html` | Страница «Услуги» (`/services`) |
| `services/*.html` | 13 страниц услуг (`brokerage`, `tenant-representation`, `facility-management` …) |
| `assets/data.js` | **Все тексты, фото и порядок услуг** — править здесь |
| `assets/app.js` | Разметка блоков и интерактив |
| `assets/theme.js` | Цвета и шрифт сайта (navy `#0b1f3a`, gold `#c9a66b`, фон `#f4f6f6`) |
| `assets/site.css` | Анимации и состояния (появление блоков, вкладки, таймлайны) |
| `assets/img/partners/` | Логотипы партнёров для бегущей строки — копии SVG из папки `Partners` |

## Для разработчика

- Разметка на тех же классах Tailwind v4, что и на сайте (`bg-primary`, `text-gold`, `container-page`, `facade-dark`,
  `ring-slate-200/70` …) и с иконками Lucide — блоки можно переносить в Next.js-проект почти без изменений.
- Шапка — копия шапки сайта из сохранённых страниц, в том же состоянии (вход под админом: «Админка», уведомления,
  аватар «НИ»). Как на сайте, при нехватке места пункты ужимаются (`data-fit`: full → dense → tight); скрипт
  переключения восстановлен по разметке — в сохранённых страницах его нет. Фавикон — те же файлы с office8.kz.
- Подвал — тоже точная копия подвала сайта. Карточки и плашки повторяют компоненты сайта.
- Плавающие кнопки — как на сайте: на телефоне «Связаться с нами», с 768px — WhatsApp с адресом страницы
  в сообщении. На страницах услуг на телефоне вместо кнопки нижняя панель, как на странице объекта.
- Фото — Unsplash по прямым ссылкам (как в блоке «Типы недвижимости» на главной). Для продакшена лучше
  заменить на свои фото объектов и команды.
- Бегущая строка партнёров — список в `data.js` (`partners`), файлы в `assets/img/partners/`. Размер знаков
  выравнивается по пропорциям логотипа (`w`, `h`), для отдельных есть ручная поправка `scale`. Логотипы серые,
  в цвете — при наведении; под курсором строка останавливается, при отключённой в системе анимации стоит на месте.
  В копию `kaz_minerals_logo.svg` добавлен `viewBox` — без него логотип в `<img>` не масштабируется.

## Что проверить перед запуском

- Тексты услуг взяты из `Services.xlsx`; опечатки исправлены, «е» → «ё» как на сайте.
- В `data.js` пометкой `// черновик` отмечены подводки, которых в таблице не было: описания трёх направлений,
  вводные для «Стратегического консалтинга» и «Property Management». Короткие плашки-преимущества под
  первым экраном каждой услуги тоже собраны по таблице — их стоит вычитать.
- Project Management: в таблице пометка «добавить из списка, который отправит Арман» — список направлений
  нужно дополнить.
- Эксклюзивный брокеридж: «выстраивание полной структуры компании…» — возможно, имелось в виду «кампании».
- Графики (аналитика, сценарии финмодели), таблица сравнения и воронка HBU — иллюстрации без реальных цифр,
  отмечены плашками «Иллюстрация» / «Пример».
- Кнопка «Связаться с нами» на телефоне открывает панель-заглушку: настоящей панели сайта в сохранённых
  страницах нет, она собрана из блока контактов подвала.
- Бегущая строка партнёров пока стоит в двух местах — сразу после первого экрана и перед подвалом. Нужно выбрать
  одно и убрать второй `${partners}` в `renderOverview()` (`app.js`).
- Логотип Eastcomtrans есть только в PNG (`Partners/logo-1.png`) — в строку не добавлен, нужен SVG.
